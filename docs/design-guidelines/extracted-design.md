# Logo-derived design direction
Supplied asset used unchanged: blue Ethereum/network, navy servers, coral advisory, green and blue role cards. Logo is branding, not a screen layout to reproduce. Navy #101e35, signal blue #246bfc, coral #f45446, mint #1eb98a; light grey work surfaces. Dense utilitarian operations console, fixed desktop sidebar, compact masthead, queue/detail split and chronological activity. DM Sans for controls, monospaced IDs; no research hero or basket motif. Mobile sidebar becomes top navigation; queue and detail stack. One actionable control per task state. No sample data passed off as live incidents. Empty deployment state explicit.
